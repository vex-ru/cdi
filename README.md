# 💾 cdi — CrystalDiskInfo Alternative for Linux

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Bash](https://img.shields.io/badge/Bash-4.0+-green.svg)](https://www.gnu.org/software/bash/)
[![Platform](https://img.shields.io/badge/Platform-Linux-blue.svg)](https://www.kernel.org/)

**Ищете аналог CrystalDiskInfo для Linux?**  
`cdi` (CrystalDiskInfo CLI) — это мощный, красивый и простой Bash-скрипт для просмотра SMART-атрибутов дисков (SATA и NVMe) прямо в терминале. Он повторяет логику и удобство оригинального CrystalDiskInfo, но создан специально для экосистемы Linux.

🇷🇺 Полная поддержка русского языка с расшифровкой каждого параметра.

---

## 🚀 Мгновенный запуск (без скачивания)

Скопируйте эту команду, вставьте в терминал и нажмите Enter. Скрипт автоматически запросит права root, проверит зависимости и запустится:

```bash
curl -sSL https://raw.githubusercontent.com/vex-ru/cdi/main/cdi.sh | sudo bash
```
(Если вы используете `wget`: 

```bash
wget -qO- https://raw.githubusercontent.com/vex-ru/cdi/main/cdi.sh | sudo bash
```

## ✨ Возможности

- 🖥️ **Знакомый интерфейс:** Цветовая индикация состояния ([+] Хорошо, [!] Тревога, [X] Плохо), как в оригинальном CrystalDiskInfo.
- 💾 **Универсальность:** Полная поддержка как SATA (HDD/SSD), так и современных NVMe накопителей.
- 🌐 **HTML-отчёты в один клик:** Генерация красивого отчёта с расшифровкой SMART прямо в браузере через Data URI (Base64). **Никаких файлов не сохраняется на диск!**
- 🇷🇺 **Понятный русский язык:** Все технические атрибуты (ID 5, 194, 231 и др.) переведены и снабжены пояснениями.
- ⚡ **Zero-Install:** Не требует установки, работает из коробки на любом дистрибутиве.
- 🛡️ **Умные зависимости:** Автоматически предлагает установить недостающие пакеты (`smartmontools`, `xclip`) только тогда, когда они действительно нужны.

## 🛠️ Использование

1. Запустите скрипт с правами суперпользователя: `sudo ./cdi.sh`
2. В интерактивном меню выберите номер диска для просмотра.
3. Нажмите **`G`**, чтобы сгенерировать HTML-отчёт.
   - Скрипт создаст Base64-ссылку (Data URI).
   - Автоматически скопирует её в буфер обмена (требуется `xclip` или `xsel`).
   - Попытается открыть отчёт в браузере по умолчанию.
   - *Совет:* Если браузер не открылся автоматически, просто нажмите `Ctrl+V` в адресной строке браузера и нажмите Enter.

## 📦 Зависимости

Скрипт проверяет наличие необходимых утилит при запуске. Если их нет, он покажет точную команду для установки.

| Утилита | Назначение | Как установить |
| :--- | :--- | :--- |
| `smartctl` | Чтение SMART-данных | `sudo apt install smartmontools` |
| `lsblk`, `column` | Форматирование вывода | `sudo apt install util-linux` |
| `xclip` или `xsel` | Копирование ссылки отчёта в буфер | `sudo apt install xclip` |

**Команды для популярных дистрибутивов:**
- **Debian / Ubuntu / Mint:** `sudo apt install smartmontools util-linux xclip`
- **Fedora / RHEL:** `sudo dnf install smartmontools util-linux xclip`
- **Arch Linux:** `sudo pacman -S smartmontools util-linux xclip`

## 💡 Ручная установка (для параноиков безопасности)

Если вы не доверяете команде `curl | bash`, вы можете скачать скрипт вручную:

```bash
# 1. Скачиваем скрипт
wget https://raw.githubusercontent.com/vex-ru/cdi/main/cdi.sh

# 2. Делаем его исполняемым
chmod +x cdi.sh

# 3. Запускаем
sudo ./cdi.sh
```
